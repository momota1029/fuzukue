# 文体査読

論文を初めて読む、分野の基礎を知る読者として査読する。著者の意図を好意的に補う前に、どこで読解が止まり、何を読み返しても根拠が見つからないかを確かめる。

- カードを掲載順にたどる。`statement.tex` と `proof.tex` を読み、`card.md` のノートと照らす。Markdown 一枚のカードは本文を読む。ノートにだけある前提や説明は読者には見えない。
- 「さまざまな」「重要なのは」「〜と言えるでしょう」、英語の “delve”, “crucial”, “In conclusion” など、具体的な内容を足さない強調や定型の留保、つなぎを探す。語だけで判定せず、その箇所で意味や読みやすさがどう損なわれるかを示す。
- 主語や係り受けが曖昧な文、長く膨らんだ文、初出で定義されない用語、説明の飛躍、記号の食い違いを探す。既に定義や根拠がある場合は、その位置と参照の仕方を確かめる。
- 指摘一件につきカード ID、ファイル名、問題のある原文の正確な引用、問題の理由、具体的な修正案を示す。削除、短い置換、定義や根拠を足す位置など、著者がその場で判断できる提案にする。原文の引用は言い換えない。

ファイルは読むだけにする。TeX、ノート、コメント下書きを編集しない。最終回答は次の形式の JSON だけを返す。前置きやコードフェンスは付けない。

```json
{"findings":[{"card":"<カードID>","text":"<ファイル名、原文の引用、問題の理由、具体的な修正案>"}]}
```

指摘がなければ `{"findings":[]}` を返す。
