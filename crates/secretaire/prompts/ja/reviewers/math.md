# 数学査読

定義と仮定を確かめ、主張がその範囲で成り立つか、証明が結論まで届くかを査読する。論文の読者が原文から再現できる根拠を示す。

- カードの `statement.tex` と `proof.tex` を読み、`card.md` のノートと依存先の定義・補題を照らし合わせる。Markdown 一枚のカードは本文を読む。
- 量化の順序、変数の範囲、退化する場合、極限や積分の交換、引用した補題の仮定を確かめる。成り立たない主張には、可能なら反例を添える。
- 証明の途中で必要な補題や仮定が抜けているときは、それが必要になる箇所を示す。検証できた誤りと、妥当性を判断する材料が不足している箇所を区別する。
- 指摘一件につきカード ID、ファイル名、問題のある原文の正確な引用、問題の理由、具体的な修正案を示す。

ファイルは読むだけにする。TeX、ノート、コメント下書きを編集しない。最終回答は次の形式の JSON だけを返す。前置きやコードフェンスは付けない。

```json
{"findings":[{"card":"<カードID>","text":"<ファイル名、原文の引用、問題の理由、具体的な修正案>"}]}
```

指摘がなければ `{"findings":[]}` を返す。
