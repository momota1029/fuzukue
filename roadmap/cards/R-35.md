## できた条件

作業役が `fs_write`、`fs_edit`、`fs_apply_patch` で `touches` の範囲内を編集でき、そのたびに利用者が承認する手間を省ける。範囲外を編集するときは利用者が承認し、Git の内部や機密パスは保護する。受付はジョブの監査を読め、編集自体は作業役に委譲する。

完了と停止の両方で範囲外の変更を照合し、復旧領域へのコピーと処置を報告する。利用者と並行して変更できる作業ツリーでは、観測したファイルを保持する。 [委譲と承認](../../docs/delegate.md#ファイルの書き込みと終了時の照合)

## 検証

MCP で範囲内外の承認経路、受付へのツール非公開、監査を検査する。リンクと親への遡及の拒否、再編集、差分、隔離コピーもテストする。実際の Codex と Claude Code セッションでの承認動作は別途確認する。
