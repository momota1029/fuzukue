## できた条件

- macOS で GPUI ウィンドウを開き、同じ Mac のサーバーとの接続、既存 PDF の表示・スクロール、日本語入力を確認する。試した OS とアーキテクチャを記録する。
- 自分のアカウントでログインした Claude Code または Codex CLI と会話できる。ターミナル起動と LaunchAgent の PATH、バックグラウンドでの認証、通知を確認する。Bubblewrap を前提とする機能は制約として記録する。
- GitHub Releases の新しい beta を検出できる。動作中のジョブが終わるまでサーバー切り替えを待ち、起動失敗時には旧版に戻る。クライアントを開き直すと対応する版になる。自動更新の停止を両方のパッケージで確認し、データを保持した手動の復旧も試す。Gatekeeper の表示と導入に必要だった操作を記録する。
