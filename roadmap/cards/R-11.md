## できた条件

secretaire が GitHub Releases のタグの完全な SHA、マニフェストの署名、成果物の SHA-256 を検証して Windows / Linux 向けの更新を進められる。自動確認は通知までとし、利用者の承認で準備・切り替えを行う。起動確認後に互換クライアントを配布し、クライアントも利用者の確認で更新・再起動する。サーバー・クライアントとも起動確認に失敗した場合は旧版へ戻る。

tailnet 外のトークン接続には TLS が必要となる。署名済み APK のインストールと `android-beta` からの更新を実機で確認できる。
