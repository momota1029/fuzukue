## できた条件

CI が Windows x86_64 のクライアント ZIP、Linux x86_64 のサーバー・クライアント tarball を作る。公開タグに対応する完全なコミット SHA、互換性情報、署名付きマニフェスト、`SHA256SUMS` を揃える。beta と stable の候補選定と、タグ・署名・ハッシュの不一致を拒否する動作をテスト用リリースで確認できる。

## 進捗

タグと手動 dry-run 用のワークフロー、パッケージ作成、マニフェストとハッシュの生成手順を追加した。ローカルで YAML と Bash の構文、およびモックの GitHub API で候補選定とタグ不一致の拒否を確認した。実際の GitHub Actions 実行、Windows / Linux のネイティブ成果物の検証、署名付きマニフェストとテスト用リリースは残件。
