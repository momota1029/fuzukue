## できた条件

Windows の PowerShell と Linux / WSL2 の POSIX ブートストラップから、検証済みの成果物をユーザー単位で導入し、固定ランチャーで起動できる。旧クライアント設定と `server-builds/current`・`previous` の移行、サービスの切り替えと失敗時の復旧、データを保持するアンインストールと再導入を確認する。開発版はローカルソースの既存経路で更新できる。

## 進捗

Linux / WSL2 のインストーラーをローカルのテスト用成果物で検証した。SHA-256 不一致の拒否、旧サーバーの移行、ロールバック、再実行、アンインストールと再導入を確認した。Windows 実機での設定移行・配布サーバーからの導入と、systemd の切り替え・起動失敗時の復旧は残件。
