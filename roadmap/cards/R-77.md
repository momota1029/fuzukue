## できた条件

- Apple Silicon の GitHub Actions ランナーで `secretaire` と GPUI の `fuzukue` をビルドする。版、タグが指すコミット、互換性情報、SHA-256 をそろえる。Intel は対応パッケージが必要な場合に同じ検証を行う。
- ランナーの一時ホームに両方を導入し、LaunchAgent を登録する。ループバックのヘルスチェックが登録済みプロセスの PID を返すこと、再起動後も確認できること、アンインストールで停止することを確認する。CLI の導入を省略してもサーバーが起動する。
- インストール済みのサーバーとクライアントが公開 GitHub Releases の beta を定期確認できる。確認に認証を使わず、ETag、確認間隔、失敗時の待機と利用者による停止を扱う。
- CI に通過した成果物を、メンテナーが指定した既存のプリリリースへ添付できる。利用者がタグを指定して初回導入・起動・再導入できる手順を用意する。
- 一行インストーラーで動作する Git、GitHub CLI、Claude Code または Codex を確認する。素の Mac で承諾後に Apple の導入画面が開くこと、完了後の再実行、公式 GitHub CLI の導入と本人によるブラウザ認証、既定の作業フォルダーでの保存から取り消しまでを確認する。

## 進捗

ビルド、ランナーでの起動確認、プリリリースへの手動添付の定義を追加した。Linux でインストーラーの Darwin 向け取得・照合のフィクスチャが通過した。macOS での初回 CI 実行、添付、公開 URL からの取得は未確認。

Apple Silicon と Intel 両方を対象に、macOS 15 以降の標準ツールで動く一行インストーラーを追加した。アプリ・サーバー・タグの照合、アプリバンドル、初期フォルダー、ローカル接続、自動更新、データを保持する削除を含む。ドライランと PR 用 CI で、両アーキテクチャの実パッケージをローカル配布フィクスチャからインストール・更新する。配布物の実行、公開 URL、Gatekeeper は macOS で確認する。

一行インストールでは、Git が使えない場合に利用者の承諾を得て Apple の導入画面を開き、完了後の再実行を案内する。GitHub CLI は版と SHA-256 を固定した公式 ZIP からホームに導入する。既定の作業フォルダーには、必要な Git の身元設定と空の初期コミットを作る。GitHub 認証はあとから行える。自動更新は従来どおりアプリとサーバーが対象。macOS CI と実機の検証は未実施。

変更履歴の専用 Git リポジトリには、保存、対象となるエージェント作業、外部編集の検知で履歴が残る。作業フォルダーの Git ブランチには保存ごとの自動コミットは行わない。次の候補は、既存の履歴取得時に最新のスナップショットを専用 Git の参照に保持し、再起動時に前回との差分を記録すること。停止中に上書きされた途中の版は対象外。
