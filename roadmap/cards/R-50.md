## できた条件

名前空間付き XML と JSON から同じ部品ツリーを作り、従来の XML 部品にも対応する。GPUI でカード、グリッド、統計、進捗、リスト、手順、折りたたみを描き、狭い幅のグリッドは 1 列になる。Android や未対応の表示ではフェンス内の原文を読める。進捗カードの撮影シナリオでダーク・ライト両方の表示を確かめる。
