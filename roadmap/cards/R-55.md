## できた条件

- 接続設定から自動更新を有効・無効にし、`stable` / `beta` / `dev` と利用できる配布先を選べる。選択中のチャネル、取得元、候補版と変更点、進捗、保留・失敗理由を確認できる。既存の URL と手動確認の導線を引き継ぐ。 `beta` の自動選択は HTTPS の接続先に互換フィードがない場合や HTTP 接続で GitHub の `android-beta` を使う。既存の空 URL は自動選択へ移行する。
- 「この提供元のアプリを許可」が必要なときに、理由と Android 設定を開く操作を表示する。戻ったときに許可状態を読み直す。システム確認が必要な場合は利用者が更新画面から開ける。許可の拒否・取り消し、確認のキャンセル後も再試行の操作が使える。
- 設定の永続化、許可の有無と設定からの復帰、手動確認、システム確認待ちを Android の画面テストで確かめる。
