## できた条件

- 認証済みの利用者がワークスペース単位で一度の操作で有効化できる。既定は 24 時間で、停止まで有効にもできる。停止・期限切れで完全承認を止める。
- 作業役は Claude Code や Codex の全面許可設定と同じように、ネイティブのシェル、書き込み、ネットワーク、push を個別承認なしで使える。受付専用ツールと設定 API は役割に従う。
- 有効化時と有効な設定の復元時に、永続キューの対象を `full_mode` で承認する。有効化時に対象の処理が待機していれば元の依頼を一度だけ再開し、利用者の判断と競合した場合は先に確定した判断を記録する。
- 停止・再有効化やサーバーの再起動をまたいで承認と一回限りの消費を保持し、同じ操作の再承認と再実行を防ぐ。朝の報告での集計は R-63 で扱う。
- 三つの OS 実行範囲と承認方針を別に選べる。bubblewrap の名前空間と実際の書き込み境界をサービスアカウントで検査し、利用不能時は理由を表示する。
