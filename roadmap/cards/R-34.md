## できた条件

1. スレッド下の一つの枠でカードの主張・証明・ノートを編集中に切り替えられる。数式プレビュー、依存リンク、版確認付きの保存、変更履歴からの取り消しを使える。
2. カード一覧、読解ページ、指摘台帳、デッキ概要、スレッドの XML `card-ref` / `finding` で同じエディタをその場に開ける。`F2` / `Enter` で開始し、`Ctrl+Enter` で保存する。`Esc` で破棄でき、未保存の変更があれば確認する。競合時は差分から解消できる。
3. 種類別テンプレートから一意な ID のカードを作り、`structure.yaml` で直後・子・章末に挿入できる。新規カードはその場で開く。
4. 移動、並べ替え、種類変更、検索による `requires` の編集、依存元を確認してからの削除ができる。UI と MCP の双方で版照合と変更履歴が働き、エージェントによる削除は承認を通る。
5. カードから組版した PDF とカードの部位内の行を同じ枠で往復できる。PDF 側で短く強調し、同じキーでカード側へ戻れる。ビルド中・失敗・古い PDF の状態が分かり、失敗時はエラー行へ進める。
6. 非カードファイルの編集と LSP の定義・参照・診断を同じ枠で使える。PDF や査読指摘からの移動も「戻る」「進む」でたどれる。どの種類の選択範囲からもスレッドに指示を送り、差分を承認できる。
7. Android では PDF の位置をタップして戻り、「PDFを見る」「ソースへ」で切り替えられる。カードの編集・追加・構成変更は長押しメニューから使える。

## 根拠

設計段階。R-03 の指摘台帳と R-10 の XML 部品をカードや位置を開く入口に使い、R-12 の差分承認へ選択範囲を渡す。 [エディタ枠の設計](../../cards/design/editor-pane.md)
