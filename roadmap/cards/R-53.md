## できた条件

- secretaire が選択されたチャネル用の `android-latest.json` と署名済み APK を HTTP で提供する。JSON は GitHub `android-beta` と同じ形式で、提示する APK は稼働中のサーバーとプロトコル互換である。WebSocket の交渉前でも取得でき、tailnet の許可リストまたは tailnet 外の HTTPS と端末トークンで両ファイルへのアクセスを認証する。
- Android のリリース処理に、自前配布先への公開工程と dry-run を組み込む。署名・ハッシュ・互換性を照合し、APK を置いた後に JSON を切り替える。失敗時は直前のフィードを維持し、直前の APK も取得できる。
- 既存のデスクトップ配布を参考に、HTTP 200 での取得、`Range` / `If-Range` での再開、無許可アクセス、旧 URL の保持、公開中断時のフィードをテストする。ログにトークンが出ないことを確かめる。
