## できた条件

- Claude Code の `claude -p` stream-json と Codex app-server を別々に検証する。配布に使う各バイナリ・対応環境で、空の作業ディレクトリ、新規セッション、送信した資料と指示、実効ツール集合が空であることを確認する。親や利用者側に置いた検出用の指示、ファイル、MCP、フックを含まないことも確かめる。CLI の版更新時に再検証できる。
- バックエンドと版ごとに、既定のシステム指示を置換できる範囲と残る追加コンテキストを記録する。実効設定や送信内容を確認できず隔離の条件を満たすと立証できない経路は、未確認または非対応と記録し、初期状態で利用不可にする。
- 合格した経路は同じ Rust 関数から本文・使用量・実行記録を取得できる。認証と購読枠を確かめ、実行前に経路と課金先が分かる。版違い、認証不足、隔離失敗、利用枠切れでは明示して止まり、通常の CLI セッションや従量 API への切り替えが起きない。
