## できた条件

- Claude Code と Codex CLI の一方だけ、両方、どちらもない場合でもサーバーは接続を受け付ける。利用できるバックエンドだけが選択肢になり、以前の設定が使えなくなった理由を画面に示す。モデル設定の既存の稼働状況通知を再利用する。
- 初回画面から、CLI の未導入とログイン未完了を区別できる。公式のインストール・ログインコマンドをコピーできる。インストールは利用者の承認、ログインは本人の操作で進める。
- 再確認ではサーバーを再起動せずに CLI の状態を読み直し、バックエンドの選択肢を更新する。認証出力、アカウント情報、資格情報をクライアントに送らない。未導入、片方のみ、ログイン後の再確認をフィクスチャで通す。
