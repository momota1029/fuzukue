## できた条件

- 受付または作業役が、公開 fuzukue ソースの検証済みコミットとスレッドから PR を下書きし、利用者の GitHub アカウント、fork、先端 SHA、宛先ブランチ、公開本文を承認画面に表示する。
- 承認後に利用者本人の fork を用意し、その作業ブランチだけに push して `momota1029/fuzukue:main` へ PR を作る。認証・承認の失効、別の fork、承認前後の差し替え、push 後の起票失敗、通信断後の重複防止を検証する。
- 完全承認モードが利用できる環境では、事前に許可された同じ fork への早送り push と PR 作成を、その範囲の承認として扱える。初回の fork 作成は個別に承認する。
