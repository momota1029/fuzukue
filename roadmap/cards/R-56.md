## できた条件

- Android 10 / 11、12、新しい対象 OS の実機で署名済み APK を更新する。OS・機種、対象 SDK、初回の導入元、更新所有者、提供元許可の状態を記録し、確認なしで更新できた条件と、システム確認が出た条件を確かめる。
- GitHub と自前サーバーの各配布経路、Tailscale と tailnet 外の HTTPS・端末トークン、切断後の再開、検証拒否、空き容量不足、確認のキャンセルを試す。作業・承認の表示中の保留と、起動時・アイドル時の適用を確かめる。
- 更新後に下書きと接続設定が残り、再接続で作業と承認の状態が戻る。問題版の公開を止め、同じアプリ ID と鍵で署名した、より高い `versionCode` の復旧 APK を配る手順を端末で通す。確認した組み合わせと結果をこのカードの「根拠」に残す。
