## できた条件

- GitHub 連携済みの受付と作業役が、シェルの承認なしでリポジトリの公開範囲、手元の HEAD の `cards.yml` の結果、指定タグのリリースとアセット、オープンの Issue を確認できる。
- PR、コミットと ref 間の比較、ファイル、ジョブとログ抜粋も読める。範囲外のリポジトリへのリクエストを止め、件数・ページ・バイトに上限を設ける。サーバーの資格情報は応答とエラーに含めない。
- GitHub のテスト用リポジトリで、公開・非公開の設定、権限不足、リリース資産、Actions の結果とログを確かめる。

## 根拠

リポジトリに範囲を絞った読み取り MCP と既存権限の一覧を追加した。`github_auth::read::tests` のモック HTTP で各ツール、許可範囲、出力の上限、資格情報の除去、キャッシュとレート制限を確認した。実際の GitHub での確認は残件。 [GitHub 連携](../../docs/github-auth.md)

書き込みの非同期承認の区分は R-47 の設計と利用手順に記録した。 [非同期の承認](R-47.md)
