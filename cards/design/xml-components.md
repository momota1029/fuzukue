## 描画と操作

- 会話の Markdown に埋め込める語彙を固定し、タグごとに GPUI の要素を対応づける。コールアウトと表は短いプレーンテキストを持ち、台帳などのドメインデータはデッキパスと ID で参照する。
- 最初の語彙は `callout`、`table`、`finding`。指摘は表示中のデッキの既存スナップショットから読む。探索ツリーと差分は後続の候補とする。
- 部品を表示する経路には HTML、スクリプト、ネットワークアクセスを持たせない。操作を加える段階ではタグとツールの対応をクライアント側で固定し、明示的なボタン操作から既存の承認経路へ要求を送る。

## 記法と互換性

- `~~~fuzukue-v1` の Markdown フェンスに XML を一要素置く。フェンスなら通常の HTML 解釈と競合せず、旧版や Android にも同一の本文を送ってコードとして読める。サーバーと履歴は元の記述をそのまま運ぶ。
- `Hello.markdown_components` はタグとスキーマ版の組の一覧とし、省略時は空とする。Android は省略する。語彙の意味や属性を互換性がなくなる形で変更する場合は、変更したタグの版と対応フェンスの版を追加する。未知のタグ・版・属性は元のコードブロックにフォールバックする。
- 受信中は閉じフェンスの行末が確定するまでコードとして表示する。行が確定し、内容を解釈できた時点で部品に切り替える。

## アクセシビリティ

- 読み上げ用のラベルに種類と内容を渡し、コールアウトは種類、タイトル、本文の順で表示する。表は見出し行から最後の行まで、各行の先頭セルから順に読む。
- 初回の部品には操作がなく、Tab 停止点を設けない。操作を追加する際は、既存の承認 UI と同じフォーカス表示とキーボード操作を使う。
