ユーザー（2026-11-19）:「チャットは自由に始めて良くて，あとから研究のスレッドになったり論文のスレッドになったりする方が綺麗に行くんじゃないかなという気がします．あとモデルはcodexのも選べると良いですね．」

決定（2026-11-19、ユーザー）: 下の提案に「お願いします」。切り替えたときは同じスレッドで続ける。作業は 1 本ずつ順番に進める。

## スレッドを会話のただ一つの単位にする

- 会話はいつもスレッドとして自由に始める。研究のタブごとの会話（`tab-<id>`）はやめ、スレッドにまとめる。
- スレッドは、あとから研究や論文のデッキに「付く」。付く先は複数でもよい。付いたデッキの文脈（題・次・関係する原稿など）を相手のシステムプロンプトに渡し、左の欄ではそのデッキの下にも出す。
- 付けるのは Claude の役目（MCP の道具）。人も付け替えられる。`create_research` は「新しい研究を作って付く」の一つの場合。既存の研究や論文に付く道具も足す。
- 縦タブの研究・論文は、デッキを開く場所と、そこに付いたスレッドの一覧になる。今ある研究タブの会話は、そのデッキに付いたスレッドとして引き継ぐ。

## 相手に Codex も選べるようにする

- モデルの一覧に、Claude のモデルに加えて Codex のモデル（Sol など。一覧は Codex のモデル情報から作る）を並べる。
- Codex のスレッドは、サーバーの `codex.rs`（app-server）で動かす。カード・論文・references などの MCP の道具を Codex にも渡す。
- 承認スタイルは Codex の承認方針と書き込み範囲に読み替える。メールを読んだ後も同じ承認スタイルを使う。
- 途中で Claude と Codex を切り替えたら、それまでの会話を新しい相手に渡して、同じスレッドで続ける。相手が変わったことは 1 行で示す。
