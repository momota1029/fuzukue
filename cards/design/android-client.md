スマートフォンとタブレットから、進捗確認と指示出しを行えるようにする。

前提: ブラウザーの画面は使わない（[[remote-access]]、「ブラウザは嫌だなあ．重いので」）。GPUI はスマホに対応していない。

## やること（指示出しだけ）

- ワークスペースとスレッドの一覧、新しいスレッド。
- スレッドで話す: 送る、止める、自分の発言と返事を Markdown と数式で読む。作業の進み具合の要約と、方針（[[agent-roles]] の方針役）の今の一手を見る。
- 承認する・断る（承認の内容は PC と同じ文で出す）。
- 終わった、承認待ち、休止して再開、を通知で知らせる。
- 論文の編集、PDF、カードの編集、設定の大半はやらない（PC でやる）。

## 実装

- `android/` に Kotlin と Jetpack Compose のアプリを置いた。スマホは一覧から会話へ進み、幅 720 dp 以上なら両方を並べる。スレッドはピン留めを先に表示する。
- fuzukue-proto のプロトコル 18 で接続する。既存の WebSocket を使い、トークンは Android Keystore の鍵で暗号化して保存する。サーバーや Rust プロトコルの変更は不要。
- 会話の差分を同じ発言に追記する。作業のカードには担当名、状態、経過時間、最新の進捗要約が出る。方針は次の一手を表示する。複数行の入力欄で送信し、応答を停止できる。
- 承認カードはサーバーから届く PC と同じ要約を使い、許可・拒否を返す。
- 会話は簡易 Markdown 表示。数式は RaTeX で描画し、描画できない式は等幅の TeX ソースを出す。
- バックグラウンド接続は設定でオン・オフできる。オンの間は前景サービスで選択中のワークスペースに接続し、応答や作業の終了、承認待ち、目標の休止・再開を端末で通知する。
- JVM で JSON と会話・作業の状態更新をテストする。Roborazzi で設定、一覧、会話、承認、タブレットをライト・ダークで撮る。実機での接続、日本語入力、通知、数式描画は未確認。[ビルドと接続手順](../../android/README.md)
