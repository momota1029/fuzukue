思いつきを、置き場所を決めずに一行から残す（従来の設計「メモは手間ゼロで置く」、[[library]] の次の段）。メモはカードなので、資料庫で探せて、あとで研究や論文のデッキに移せる。

## 置き場所

- プロジェクトの根に `memos/` のデッキを置く（`deck.toml` の `kind = "memos"`、題「メモ」）。最初のメモを書く時に作る。git に入るので、別の PC でも見える。
- 一枚のメモは `memos/<id>/card.md`。ID は日付と最初の語から作る（`2026-11-20-sphere-concentration`、重なれば `-2`）。`kind: memo`。題は一行目（長ければ切る）、本文は書いた文そのまま。
- 出どころがあれば `from:` に書く（スレッドの発言、資料の該当ページ、カード）。
- 縦タブの研究の一覧には出さない。左の欄の「資料庫」の中で扱う。

## 書く

手間を最小にする。題、種類、デッキは訊かない。

- **資料庫から**: 検索欄の下に「メモを書く」の欄。複数行で書けて、Ctrl+Enter（または「残す」）で保存する。保存したら欄を空にして、一覧の先頭に出す。
- **会話から**: 発言の操作に「メモに残す」。その発言の本文（選んでいればその部分）をメモにして、`from:` にスレッドと発言を書く。
- **受付・作業役から**: MCP に `add_memo {text, from?}` を足す。利用者が「メモしておいて」「覚えておいて」と言った時に使う。受付の道具の案内に一行足す。

## 探す・見る

- 資料庫の種類に「メモ」を足す（`LibraryKind::Memo`）。`memos/` のカードはカードの種類ではなくメモとして出す。
- 資料庫で検索語が空の時は、新しいメモを並べる（新しい順）。
- 結果を押すと、メモをその場で開いて編集できる（作業台の編集と同じ。保存して閉じる）。

## 移す

- メモの行の「移す」でデッキを選ぶ（デッキの検索 `SearchDecks` を使う）。メモのフォルダを移し先のデッキに移し、`kind` は `memo` のままにする（移した先で人や作業役が種類を決める）。`memos/` にはもとの ID だけを書いた一行を残さない（移した記録は git に任せる）。
- 移し先の候補を作業役に提案させるのは次の段。

## 次の段

- PDF の選択、メールからメモ。

## 実装

資料庫の入力欄と会話の発言からメモを残せるようにした。会話から残すと発言の全文とスレッド・発言の ID を保存する。資料庫では検索語を空にすると更新順にメモを表示し、行を押すと既存のファイルエディタで開く。「移す」では既存のデッキ検索を使い、移したメモは移し先のカードとして索引に載る。MCP の `add_memo` も同じ場所に保存する。Workbench はプロトコル 24 から対応する。 [使い方](../../docs/library.md#メモ)
