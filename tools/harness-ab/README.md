# ハーネスの A/B 計測

リポジトリ直下でサーバーをビルドする。

```sh
cargo build -p secretaire
python3 tools/harness-ab/ab.py
```

静的計測ではサーバーが組み立てる Claude の追加システムプロンプトと、MCP の `tools/list` の結果を測る。JSON は空白を省き、Unicode をエスケープせずに比較する。文字数と UTF-8 バイト数を出し、バイト数をトークン量の近似に使う。Claude 固有の既定プロンプトやツールはこの計測に含まれない。

実測には認証済みの `claude` が必要。作業役に Codex が選ばれた場合は、サーバーが通常どおり `codex` も起動する。

```sh
python3 tools/harness-ab/ab.py --live > harness-ab.jsonl
```

各依頼を新規スレッドで一回ずつ実行し、Claude の最初のターンを測る。MCP の設定と権限は通常のサーバーの起動経路で決まる。作業役の完了後に届く別ターンや、作業役自身のトークン数は集計に含まない。結果には返信本文、かなの有無による日本語判定、`だよ`・`だね`・`私` の出現、`delegate` の呼び出し、指定された作業役、入力・出力トークン数を含む。入力にはキャッシュ作成・読出しも足す。各トーン指標は文字列の検出なので、実際の口調は返信本文で確認する。

既定の計測対象は `examples/lab` のコピー。計測用の小さな日本語の文体スキルをコピーにだけ置く。既定の口調はリポジトリの `AGENTS.md`。各試行は別の一時ワークスペースで行い、MCP はループバックで待ち受ける。通常利用中のサーバーやメール設定は使わない。

実際のルールパックを含むワークスペースで比べる場合は `--project /path/to/workspace` を指定する。ワークスペースをコピーするため、相対パスで隣のディレクトリを指しているルールパックは、計測用のコピーを用意してパスを調整するか、絶対パスで参照する。依頼は `--samples` で差し替えられる。形式は [samples.json](samples.json) と同じ。口調ファイルは `--user-instructions /path/to/AGENTS.md` で指定できる。
