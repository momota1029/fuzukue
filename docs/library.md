# 資料庫

サイドバーの「資料庫」で、ワークスペース内の参考資料、カード、スレッド、コメントの下書き、外部査読報告をまとめて検索できます。種類は複数選択でき、選択をすべて外すと全種類が対象になります。デッキを選ぶと、そのデッキのカード、コメント、査読報告と、添付先にそのデッキを含むスレッドに絞ります。参考資料はワークスペース全体の資料として扱います。

デッキやスレッドなどを開くための検索は、これとは別です。画面上部の帯で GitHub と設定の左にある検索ボタンを押すか、Ctrl+K（Mac は ⌘K）で開き、Esc で閉じると直前の入力先に戻ります。

日本語は部分文字列、ラテン文字と数字は大文字と小文字を区別しない単語で照合します。関連順では TF-IDF を使い、題やカード ID、定義語の一致を重く扱います。「新しい順」では更新時刻で並べ替えます。結果は最大 50 件ずつ表示されます。

結果を選ぶと、PDF のページ、テキスト資料の行範囲、論文またはカードの画面、スレッドの発言、デッキのコメント欄、査読の指摘を開きます。指摘を未確定の報告は、原文を開きます。参考資料の検索には抽出済みのコーパスを使います。新しく追加した資料は抽出が済むと検索に出ます。 [参考資料の仕組み](../cards/design/references.md)

資料庫の「台帳」では、集める資料、試した取得先、取得済みファイルを確認できる。 [取得の台帳](ledger.md)

MCP の `search_library {query, kinds?, deck?, limit?}` も同じ索引を使います。種類は `reference`、`card`、`thread`、`comment`、`memo`、`review_report`、デッキはワークスペース相対パスで指定します。結果の資料キー・ファイル・ページまたは行範囲は `read_reference` に、カードのデッキと ID は `card_read` の `deck#id` 形式に使えます。

## メモ

検索欄の下の「メモを書く」に本文を入力し、Ctrl+Enter または「残す」で保存する。保存すると入力欄が空になり、絞り込みを外して最近のメモを表示する。会話の「メモに残す」は発言の全文を保存し、`from:` に `thread:<スレッド ID>#<発言 ID>` を書く。

初回の保存でプロジェクトの根に `memos/` デッキを作る。各メモは `memos/<id>/card.md` に置き、`kind: memo` を付ける。ID はサーバーのローカル日付と本文の最初の語から作り、ASCII で表せない語には短いハッシュを使う。重複時は `-2`、`-3` と続く。題は一行目の先頭 80 文字。本文は入力したまま保存する。

検索語が空で種類の指定がないか「メモ」を含むときは、`memos/` のメモだけをファイルの更新時刻が新しい順に並べる。デッキの絞り込みは空の検索にも効く。検索語があるときは、ほかの種類と同じ規則でメモを探せる。

メモの行を押すと Workbench のファイルエディタで `card.md` を開く。保存するとエディタが閉じて資料庫に戻る。「移す」でデッキを選ぶと、そのデッキの最初のカード用ディレクトリへフォルダごと移る。同じ名前のフォルダがある場合は移動を中止する。移したカードの `kind: memo` はそのままで、資料庫では移し先の「カード」として検索できる。

MCP の `add_memo {text, from?}` は保存したメモの ID とパスを返す。受付と、このツールを許可された作業役が使える。`search_library` では `memo` を種類に指定でき、空の `query` で最近のメモを取得できる。Workbench のメモ機能はプロトコル 24 から使える。
