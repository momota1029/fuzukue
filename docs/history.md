# プロジェクトの変更履歴

プロトコル 29 以降の作業台では、カードの「履歴」、エージェントの発言と委譲の完了報告の「この仕事の変更」、情報欄の「最近の変更」から差分を開ける。記録には時刻、変更ファイル、要約と、分かる場合はスレッドとターンが付く。エージェントの要約は最後の発言の最初の空でない行を 160 文字まで使う。発言がない場合や通常の保存ではパスを使う。

## 記録の境界

- カード編集、作業台のファイル編集、ソースエディタは、保存の前後の実ファイルを比べる。内容もファイルモードも同じなら記録を作らない。拡張機能の権限付きファイル書き込みも、書き込みごとに記録する。
- Claude と Codex のターン、委譲した仕事、査読ランナーは開始と終了で作業ツリーを比べる。ロール名またはバックエンド名を `agent:<名前>`、査読の種類を `reviewer:<種類>`、拡張機能名を `extension:<名前>` として保存する。中断や失敗までに残った差分も記録する。別の作業ツリーで実行した仕事の差分は、このワークスペースに取り込まれた時点で対象になる。
- 実行中に利用者が保存した差分は `human` として記録し、ターンの差分から外す。ターン中に同じファイルを先にエージェントが変更し、続いて利用者が保存した場合は、そのパスをターンの記録から外す。開始・終了時の内容だけでは、そのパスへの書き込みを正確に分離できないためだ。複数のターンで同時に作業すると、書き手の分からない変更は先に終了したターンに入ることがある。
- ターンの外にあるファイルシステムの変更は、サーバーの監視でまとめて `external` として記録する。外部エディタの書き込みには書き手の情報がなく、実行中のターンと重なるとそのターンの差分に含まれることがある。短時間で作成・削除されたファイルやサーバー停止中の編集は、スナップショットの間に消えると捕捉できない。

保存先はワークスペースごとのサーバー状態ディレクトリ内の `history.git`。Git CLI に `GIT_DIR`、`GIT_WORK_TREE`、`GIT_INDEX_FILE` を指定し、利用者の Git の HEAD、ブランチ、インデックスを更新せずに、影のリポジトリでオブジェクトを管理する。`.gitignore`、利用者の `info/exclude` とグローバルの除外を読む。Git メタデータ、サーバー状態ディレクトリ、会話の自動保存先 `threads/`、ビルド先（`target`、`build`、`.lake` など）は対象外。入れ子の Git リポジトリと UTF-8 で表せないパスも対象外となる。通常のファイルは生のバイト列を保存し、シンボリックリンクはリンク先のパスを記録する。

各記録のコミットメッセージに JSON のメタデータを保存する。コミットとその親は変更対象のパスだけを含む独立した組で、公開する記録 ID はコミットのオブジェクト ID。ターンのコミットには会話の発言 ID も保存するため、再接続後も会話から差分を引ける。

## 戻す

「戻す」は選んだ記録全体の差分を逆向きに適用する。現在の内容とぶつかった場合は、適用できなかった箇所が出る。その場で「戻せる箇所だけ戻す」か「やめる」を選べる。確認後に対象が変わった場合は再評価する。現在の除外ルールに該当するパスは変更しない。

「カードをこの時点に戻す」は、その記録の直後にカードが持っていた内容を復元する。現在のカードの Markdown と、フォルダ型カードでは同じフォルダの TeX が対象。残っている記録の変更前後から各ファイルの内容を求める。カードを移動した場合は現在のパスで履歴を探す。削除されたカードそのものを戻したいときは情報欄から削除の記録を開く。復元と取り消しはどちらも新しい `human` の記録になり、再び「戻す」で逆にできる。

変更を戻す操作は作業台の WebSocket から実行する。エージェント向けの MCP に取り消しや復元の道具はない。

## 保存期間

既定では直近 90 日以内かつ最新 2,000 件を残す。サーバーの状態ディレクトリに `history.toml` を置くと、ワークスペースごとに上限を変えられる。既定ワークスペースの場所はサーバー起動ログの `state:` に出る。追加したワークスペースはその配下の `workspaces/<id>/` を使う。

```toml
days = 90
records = 2000
```

上限を過ぎた記録への参照は記録・参照・監視の処理時に削除する。古いコミットが新しい記録の親になっていないため、新しい記録の差分を保ったまま、実行中のターンがなくなったところで不要な Git オブジェクトを `git gc` でまとめて回収できる。
