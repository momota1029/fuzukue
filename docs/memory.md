# 受付の記憶

全体の記憶は `~/.fuzukue/memory/`、仕事場の記憶は `<workspace>/.fuzukue/memory/` に保存する。記憶の範囲は保存時に選ぶ。仕事場がホームそのものなら全体の範囲を使う。正本は `items/<id>.md` で、目次は正本から作り直す。現在の仕事場と全体を合わせて、上限は 200 件、目次は 32 KiB。保存先は端末内の私的なディレクトリで、fuzukue による自動同期は行わない。

利用者が直接話したターンには、選択中の Claude または Codex に現在の目次を送る。受付が項目を開くと本文も同じ提供先に送る。覚えてほしいことは受付に伝え、全体か仕事場か、作業役にも渡してよいかを指定できる。作業役へは受付がその依頼に選んだ項目のうち、作業役への共有を許可された本文だけを、その作業役のモデルに送る。

## 削除と取り込み

削除したい項目を受付に伝えると、対象と確認用の文が表示される。その文を同じ会話で送ると、表示された版を照合し、削除前のファイルを私的な控えに保存する。版が変わっていた場合は、現在の内容から確認をやり直す。同じ確認は一度だけ使える。

Claude Code の記憶を取り込むときは、実際に使っている元ディレクトリを受付に伝える。プレビューでファイルを読んだとき、その内容は現在のモデル提供先に送られる。候補の一覧で、取り込む項目と行範囲、全体か仕事場かを選ぶ。目次の `MEMORY.md` も候補に出るので、索引だけの行と残したい内容を見分けられる。候補の本文や要約を直すこともできる。受付が示す最終プレビューを確認し、確認用の文を同じ会話で送る。

取り込み前に全体と現在の仕事場の正本を、全体の保存先にある `backups/imports/` の日付付きディレクトリへ控える。途中で止まった場合は、同じ元ファイルからプレビューをやり直すと、すでに取り込んだ項目を除いて続けられる。元ファイルと Claude Code の設定はそのまま使える。

## アプリが管理する範囲

外部イベントや外部コンテンツから起動したターンには、新しい記憶の目次を送らない。CLI が登録済みのツール名を覚えている場合も、アプリは専用ツールの呼び出しを拒否する。保存は書き込み可能な利用者ターンに限り、削除と取り込みの適用には会話内での利用者本人の確認が必要になる。以前のターンで渡した目次や本文は、通常の会話履歴と同じようにモデルの文脈に残ることがある。記憶の削除は、会話履歴、ログ、提供先の保持データには及ばない。

fuzukue の汎用ファイルツールは、全体と仕事場の記憶ディレクトリを読み書きや検索の対象から除外する。作業役のファイルアクセス制御と実行サンドボックスも同じ保存先を保護する。フルアクセスの実行や fuzukue の外で動くプログラムは端末の権限に従う。共有フォルダー、同期サービス、Git 操作を通じてファイルが外部に出る可能性があるため、保存先は私的な場所として扱う。
