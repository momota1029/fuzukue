# 応対役・作業役のモデル設定

デスクトップの設定から「作業役」→「モデルと使用量」を開くと、応対役、作業役の既定、作業の段階、相談役、要約、スレッド名、一時変更で使うモデルと思考レベルを選べる。個別の作業役は「作業役」一覧で選ぶ。変更は保存後の次のターンや新しい委譲に反映される。応答中のモデルは、そのターンの終了まで使われる。

スレッドの情報欄で、次のターンに選ばれる応対役のモデルと思考レベルを確認できる。個別の変更は入力欄または情報欄のモデル・思考レベルから行う。「ワークスペースのモデルと思考レベルに戻す」で既定の継承に戻る。スレッドでモデルを明示した場合は、ワークスペースの応対役設定より優先される。

同じ提供元での切り替えは保存済みセッションを使う。Claude Code は必要に応じてプロセスを起動し直し、同じセッション ID で再開する。Codex は同じ app-server スレッドの次のターンにモデルと思考レベルを指定する。提供元をまたぐ場合は保存済みの履歴から作った会話の抜粋を引き継ぐ。返答の詳細には実際の実行情報が残る。

## 一時的に強いモデルで答えてもらう

入力して「強いモデルで送る」を押すか、`/escalate 続きのメッセージ` と送る。入力欄のボタンは応答を待っていないときに使える。一時変更用の指定があれば最優先で使い、省略時は相談役の設定、重量の段階設定、方針役のモデルの順で選ぶ。返答にモデル名つきの印がつき、次の通常のターンはスレッドの指定かワークスペースの既定に戻る。指定のモデルを利用できなければ理由を表示する。相談役から助言を得て応対役が答える方法には、既存の `consult` も使える。

## 委譲に使うモデルの優先順

1. 一回の `delegate` に渡した `model` と任意の `effort`。
2. スレッド内の役別指定、その後にワークスペースの役別指定。名前なしの委譲ではスレッド個別の作業役指定を使える。
3. 軽量・標準・重量の段階設定。稼働状況によって段階や段階内の候補が調整される。
4. 作業役のワークスペース既定。作業役の既定を明示していない場合、名前つきの作業役は定義のモデルを起点にする。

たとえば `delegate` に `{"agent":"prose","prompt":"用語の統一を確認する","model":"gpt-6.2-sol","effort":"high"}` を渡すと、そのジョブだけで指定のモデルを使う。思考レベルはモデルが対応する値を選ぶ。ブラインド査読では `backend` と提供元 API の `model` を指定する。ジョブの詳細や作業履歴には実際の選択が残る。

## サーバーで設定する

接続中のワークスペースに対して `get_server_settings` に `{"models":true}` を渡すとモデル設定を取得できる。`set_server_settings` の `model` には設定する役（`front_desk`、`worker`、`agent`、`worker_tier`、`consult`、`summary`、`thread_title`、`escalation`）、モデル ID の `name`、任意の `effort` を指定する。`agent` には役の名前、`worker_tier` には `light`、`standard`、`heavy` のいずれかを渡す。作業役の既定には具体的なモデルが必要。応対役で `name` を省略すると Claude Code の CLI 既定を選び、その他の役では個別指定を解除する。従来どおり、査読設定は同じ道具の `review` で更新できる。

サーバーを運用する利用者は、ユーザー設定ディレクトリ内の `fuzukue/fuzukue.toml` に全ワークスペース共通の既定を書ける。ワークスペースごとのサーバー状態ディレクトリにも同名のファイルを置ける。ワークスペースの保存済み UI 設定、ワークスペースの状態ディレクトリの TOML、ユーザー設定ディレクトリの TOML の順に優先され、次のターンや委譲で読み直される。プロジェクトの作業ツリーにある TOML には、応対役と作業役の実行設定を委ねない。

```toml
[models.front_desk]
model = "claude-sonnet-5-5"
effort = "medium"

[models.worker]
model = "gpt-6.2-sol"
effort = "high"
```

Android では通常のメッセージ欄から `/escalate メッセージ` を送れる。役別の選択画面とモデル名つきの返答表示はデスクトップで利用できる。
