# フォルダーの読み取り許可

デスクトップで対象スレッドの詳細を開き、「フォルダーを追加」からサーバー上のフォルダーの絶対パスと許可期間を入力します。受付や作業役が範囲外のパスを読むと、会話にフォルダーの許可依頼が表示されます。表示されたパスを確認し、必要な期間を選ぶか、拒否します。Android の承認カードには「1 時間許可」と「拒否」が表示されます。

| 期間 | サーバーで許可が終了する時点 |
| --- | --- |
| このターンだけ | 受付の現在のターンが終了した時点、またはサーバー再起動時 |
| 1 時間 | 許可から 1 時間後 |
| 今日中 | サーバーの現地時刻で翌日が始まるとき |
| スレッド終了まで | スレッドをアーカイブするか、ゴミ箱に移したとき |
| 無期限 | 取り消すか、スレッドをゴミ箱に移したとき |

スレッド詳細の「フォルダー」で、有効な許可と期間、許可した利用者を確認し、取り消せます。アーカイブ中のスレッドへの許可は停止します。「読み取り履歴」には、許可を使った操作のスレッド、パス、時刻に対応する記録が新しい順に並びます。取り消し後も履歴を参照できます。

## MCP

受付の `folder_grants` は、`action: "request"` とサーバー上の絶対フォルダーパス `path` で利用者に承認を求めます。`action: "list"` は現在のスレッドの許可と読み取り履歴を返します。応答の `audit_before` を次の一覧取得に渡すと、古い履歴を取得できます。`action: "revoke"` と `grant_id` で取り消します。

許可は `fs_read`、`fs_list`、`fs_search`、`git_show` の読み取りに適用されます。外部の Git 履歴は `repository` に許可フォルダー内のリポジトリの絶対パスを、`path` にリポジトリ相対パスを指定します。外部リポジトリはローカルの `.git` ディレクトリを持つ通常の SHA-1 形式に対応します。履歴取得には参照とオブジェクトの一時コピーを作成し、上限は 256 MiB です。そのコピーから外部設定、代替オブジェクトストア、ネットワークへのアクセスを排除します。

作業役への委譲には、`delegate` の `folder_grants` に共有する有効な許可の ID を指定します。省略時は空です。委譲後の読み取りにも元の許可の期限と取り消しが適用されます。読み取り許可はシェル、ファイルの編集、書き込み、アップロードの権限を追加しません。

## 保護対象

サーバーは実パスを確認し、許可で追加された範囲ではシンボリックリンクを経由する読み取りを拒否します。`..` を含むパス、ハードリンクされたファイル、Git の内部ファイルへの通常の読み取りも拒否します。

[サーバーの `SENSITIVE_PATHS` 定数](../crates/secretaire/src/folder_grants.rs) は、SSH・GnuPG・AWS などの認証情報、GitHub CLI とその他の認証情報、ブラウザーのプロファイル、シェルの履歴、システムのパスワードファイルなどを保護します。サーバー自身の設定と状態ディレクトリ（既定の `~/.local/state/fuzukue` を含む）には、親フォルダーに許可があってもアクセスできません。既存の読み取りツールでは `.env` や秘密鍵などの名前も保護します。
