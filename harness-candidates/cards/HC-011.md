## 目的

    Measure server allocation, anonymous residency, and transcript write amplification on reproducible synthetic multi-workspace workloads.

## 使った手段

    Build a filtered offline test with a counting system allocator. Drive deck routes in-process, seed synthetic transcripts, publish synthetic worker events, and record phase counters including /proc/self/smaps_rollup and /proc/self/io. Run it twice on isolated revisions with the same fixture and compare JSON metrics.

## 既存ツールで足りなかった理由

    Loopback networking and the user manager can be unavailable in workers. There is no repeatable server-scale memory and write benchmark recipe.

## 提案する引数と戻り値

    benchmark_server_memory(revision, workspaces, decks, threads, allocator_tuning)
