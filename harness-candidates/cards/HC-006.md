## 目的

    Package one job's edits as a patch from a shared dirty checkout

## 使った手段

    Save byte-for-byte baselines of named paths before editing. Diff each baseline against its current path with git diff --no-index, normalize paths, combine only those hunks, then run git apply --cached --check and report conflicting context.

## 既存ツールで足りなかった理由

    Existing Git tools show the shared checkout's changes. A worker needs a patch against its own pre-edit baseline without staging shared changes.

## 提案する引数と戻り値

    snapshot_paths(paths) -> snapshot_id; export_scoped_patch(snapshot_id, paths, output) -> patch and apply check
