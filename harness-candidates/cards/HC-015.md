## 目的

    Run desktop unit tests in fixed-size batches, one process each, with a private target directory

## 使った手段

    cargo test <manifest> --features <headless> -- --list > names; for each chunk of N names: cargo test ... -- --exact <chunk> > batch-i.log; print exit status per batch

## 既存ツールで足りなかった理由

    A single-process full run leaks threads, and no configured tool batches the tests or summarizes the per-batch results.
