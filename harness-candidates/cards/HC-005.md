## 目的

    Verify and export one job's patch while other jobs edit the shared checkout

## 使った手段

    Archive the selected Git base to a temporary checkout, replay the job's exact tracked file edits there, and export git diff for the job's touched paths. Verify with git apply --cached --check against the shared index without staging anything.

## 既存ツールで足りなかった理由

    Independent jobs can modify the same large source files, making a path-filtered shared diff include another job's hunks. An isolated replay also gives tests a consistent source tree.
