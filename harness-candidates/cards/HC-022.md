## 目的

    Build or test two checkouts of one Cargo workspace against a shared target directory without reusing each other's workspace-crate artifacts

## 使った手段

    cargo build --config profile.dev.package.<crate>.codegen-units=<unique> (repeated per workspace crate) -p <package>

## 既存ツールで足りなかった理由

    Path crates get the same artifact hash in both checkouts and freshness is judged by file time, so one checkout can link the other's modified crate and fail to compile or test the wrong code
