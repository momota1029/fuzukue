## 目的

    Run desktop Cargo tests with a writable off-repository temporary directory

## 使った手段

    Run Cargo from the job temp directory. Give the child processes TMPDIR, TMP, and TEMP via /proc/<parent-shell-pid>/cwd, keep that shell alive, pass the checkout's manifest path, and provide temporary linker aliases for installed Linux runtime sonames.

## 既存ツールで足りなかった理由

    Clang interprets percent signs in its temporary-file template. In worker directories whose names contain percent signs, direct desktop builds can fail before invoking the linker.

## 提案する引数と戻り値

    run_desktop_cargo(manifest, cargo_args)
