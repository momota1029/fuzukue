## 目的

    Verify that a stack of patch files applies in order onto a clean export of a revision

## 使った手段

    git archive REV | tar -x -C SCRATCH; git -C SCRATCH init -q; for p in PATCH...; do git -C SCRATCH apply "$p"; done

## 既存ツールで足りなかった理由

    Follow-up patches must be checked on top of one or more unmerged patches, with and without an extra patch. No tool covers this without a hand-written pipeline.
