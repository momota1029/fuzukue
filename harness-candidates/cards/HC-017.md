## 目的

    Build and test a patch in an isolated clone with private build and temp directories

## 使った手段

    env TMPDIR=<dir> CARGO_TARGET_DIR=<dir> CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 timeout <seconds> cargo test -q -p <crate> -- <filters> > <log> 2>&1

## 既存ツールで足りなかった理由

    Workers had no test tool that runs in an isolated copy with a private CARGO_TARGET_DIR and TMPDIR, so each run needed a long raw shell command, plus polling and manual termination of hung test binaries.

## 提案する引数と戻り値

    run_tests(dir, target_dir, tmp_dir, suite, filter, timeout)
