## 目的

    Run selected Rust Desktop tests in restricted Linux workers

## 使った手段

    Build the selected Desktop binary test target with cargo rustc --profile test and its headless feature. Set writable non-repository TMPDIR, TMP and TEMP, make temporary linker aliases for runtime libraries, and if the configured clang linker cannot use response files, use a per-invocation GCC shim that forwards arguments to the existing mold linker. Read the test executable path from Cargo's compiler-artifact output and run it with the requested filter.

## 既存ツールで足りなかった理由

    The worker can type-check the test target but its configured clang driver may fail before executing the linker. A scoped fallback can reuse the existing target cache without changing workspace or user Cargo configuration.

## 提案する引数と戻り値

    run_desktop_tests(filter)
