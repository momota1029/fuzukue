## 目的

    Run native Cargo tests when the worker temporary path contains percent signs

## 使った手段

    exec {job_tmp_fd}< "$TMPDIR"
    export TMPDIR="/proc/$$/fd/$job_tmp_fd" TMP="/proc/$$/fd/$job_tmp_fd" TEMP="/proc/$$/fd/$job_tmp_fd"
    exec or run the selected Cargo test while the owning shell stays alive

## 既存ツールで足りなかった理由

    Clang's temporary filename pattern treats percent signs as placeholders. A normal writable TMPDIR can still make the linker fail with 'unable to make temporary file'. A Linux /proc directory descriptor alias gives Clang a percent-free path to the same job-owned directory.
