## 目的

    Verify a patch built in an isolated copy under target/

## 使った手段

    git clone --shared <repo> <scratch>/src; run cargo test with CARGO_TARGET_DIR, TMPDIR, XDG_* under <scratch>; git -C <scratch>/src diff --output=<scratch>/change.patch; git apply --check on a fresh clone, optionally after <other.patch>

## 既存ツールで足りなかった理由

    Workers repeatedly clone the checkout, run cargo with a private target, TMPDIR and XDG dirs inside the workspace, export a patch, and check that it applies on HEAD and after another pending patch.
