## 目的

    Verify rolling Android release publication in a local fixture without contacting GitHub.

## 使った手段

    Create a temporary app build fixture and stub build, signer, and release CLI commands. Run the release script against the stub, record release API calls, and assert first publication, rolling update, unchanged retry, and feed restoration after a simulated upload failure.

## 既存ツールで足りなかった理由

    Release dry-run previews actions. It takes a stubbed CLI and build fixture to exercise asset order, immutable filenames, retries, and feed rollback.
