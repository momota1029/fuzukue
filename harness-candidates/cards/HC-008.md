## 目的

    Type-check a Rust desktop crate for Apple Silicon from Linux when the Darwin SDK is unavailable

## 使った手段

    In an isolated checkout, run cargo check --locked --target aarch64-apple-darwin using an installed Apple Rust target. Use a target-specific CC/CXX shim that emits empty Mach-O objects for native source compile steps, and supply placeholders for any host-gated shader includes. Keep all shims and outputs out of the patch and report that native linking and shader validation still require macOS.

## 既存ツールで足りなかった理由

    Native C build scripts and host-gated shader generation prevent a source-level Apple target check on Linux. A reusable check can get past them and distinguish Rust type errors from native build and linking failures.
